ПРАКТИЧЕСКАЯ РАБОТА. ДЕНЬ 11
Git: репозиторий, коммиты, история, ветки и удалённый репозиторий
1. Что будем делать сегодня
Разберём, зачем нужна система контроля версий.
Поймём разницу между Git и удалённым сервисом хранения репозиториев.
Проверим, что Git доступен.
Настроим имя и электронную почту Git на учебном компьютере.
Создадим локальный репозиторий.
Разберём рабочую папку, индекс и коммит.
Научимся использовать git status, git add и git commit.
Посмотрим историю через git log.
Научимся сравнивать изменения через git diff.
Создадим ветку и переключимся на неё.
Выполним слияние ветки.
Подключим заранее подготовленный удалённый репозиторий.
Разберём git push и git pull.
Выполним большой самостоятельный блок с постепенным усложнением.

2. Что такое система контроля версий
Система контроля версий хранит историю изменений файлов проекта. Она позволяет видеть, что менялось, когда это происходило и к какому состоянию проекта можно вернуться.
Git особенно полезен, когда программа развивается постепенно или над проектом работают несколько человек.
